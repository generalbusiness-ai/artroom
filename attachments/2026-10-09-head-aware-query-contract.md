## Nouns and verbs

A query selects one kind, status mode and bounded page, or one exact detail subject. A component is an actual scope read: full scope reference/incarnation, head seq/hash, pinned definition, provenance and completeness. A view combines components; there is NO atomic room head. A cursor is an opaque authenticated position bound to query/version/origin/full scope/ref/head, never authority. An invalidation says a component may be newer; it is not content, permission, settlement or proof of a command's result. An inspection family is optional history/reviews/jobs/links/comments/operations outside the primary subject.

Read a visible page; verify the selected subject; invalidate when a relevant head changes; refresh through actual authenticated reads; continue a cursor only at its stated scope head; inspect optional families on demand. Never use a stale projection to decide a native act or rebuild an unknown intent.

## Source-derived baseline, not measurements

Current Page data.ts listLanes reads a directory summary, then sequentially reads EVERY listed lane summary and retained final main items if needed, before kind/status filtering in the view. Let L be listed rows with scope, F their final-main retained pages: list loading costs 1+L+F scope reads, plus an optional session refresh. Directory summary itself returns all live lane index rows up to the definition's live bound, not a visible-page query. The directory's copied title/state/seen values are advisory; lane reads supply actual current title/state at separately observed heads. Current final items are fetched through itemsOf even when this means enumerating unrelated final items; no room-wide result count is inferred from one head.

loadChange gets lane summary/definition, eagerly collects proposal, manifest, review, review-request, job, link, merge and comment families, selected source and detached body texts, and destination publication history before rendering. itemsOf combines summary live rows with all final-item pages, at most100pages per family. It rejects failed/incomplete/mixed-head enumeration. publicationsOf gets destination summary, all publication items, filters them by lane operation, then scans all destination history (at most1000pages) to reconstruct operations before selecting those belonging to that lane. For H destination history pages and P retained publication pages, its cost is1+P+H (when any matching publication exists), not proportional to the selected merge. For the detail as a whole, finite request count is 1 lane summary + D declaration reads (D=0 for an existing cached exact declaration, otherwise D=2: ScopeHandle.definition reads another summary and then the retained declaration) + ΣF_t final-item pages for each requested item family + S selected source-entry/text reads + T detached body/comment text reads + G destination reads (G=1+P+H when matching publications exist; G=1+P when none match and no history scan runs), plus optional session refresh. Eight logical families are not eight independent live-item HTTP calls: live items already arrive in the lane summary; only their final pages and source/text lookups add calls. Page budgets bound failure, not server asymptotic work or total decoded allocation.

Current server reads.summary loads live items for every declared type; items is a final-items page by numeric ID; history is numeric-position pagination bounded200entries/1MiB, with current head in each answer. Existing client pagesOf rejects movement between pages rather than silently stitching heads. Server reads.operations/operation and SQL operationsFor/operationStatus exist internally, but public ScopeApi/client transport and Worker HTTP routes do not expose those operation queries. operationsFor currently materializes its entire result; there is no public bounded selected-publication query or server title/status search. A new Page call must not pretend these missing methods already exist.

Composed eac95 retains these list/publication loops and adds exact LIST1 source/provenance and native review defaults; it does not fix query scale. This baseline is static source-derived counts, not cold/warm timing evidence. No retained capture timing is substituted as a growing-room measurement.

## Smallest server slice proposed for adoption

1. Directory index-page query: one kind issue/change, order by recorded stable number then scope identity, optional ADVISORY copied-status filter, limit and opaque cursor. Explicitly return directory-copy title/state/seen and their provenance, not current lane truth. SQLite needs maintained native index keys for kind/status/order (or an internal projection table atomically derived from native index entries). Current item_by_state lists only item lifecycle, and lane rows all remain listed; it cannot provide those filters by itself. Do not scan all JSON rows or download all lanes then label the result paged. 2. Selected lane-primary query: exact full lane reference + optional selected manifest/merge FactRef, bounded proposal/main item and selected version source, current small rule requirements and latest merge linkage. Primary title/state/ selected version can render after this component, before unrelated families. Source bytes/diff disclosure and bounds remain N1's; primary source may be unavailable without hiding the retained subject. A selected older version stays older visibly; it never silently switches to latest. 3. Destination selected-publication query: input exact lane merge FactRef, destination full ref and selected publication ID if known. Use native operation index mapping and paged operations-for-publication, with written receipt/proof handled by A1. No full destination history scan. Return native publication state, judged fact, written receipt status and separate operation attempts; confirmed internal operation alone never becomes Merged. No provider call is needed for this native projection. A1 retains fetched Git receipt/immutable Site correspondence; this query cannot grant public Site permission.

These are PROPOSED domain read operations, not current routes/methods. Names and exact wire shape must be fixed in the scope/authority/read contract before implementation. No public generic reader, broader source disclosure or new native act is implied. The projection computes presentation from stored native records; it does not judge eligibility anew or turn an advisory index into a native authority statement. Signed intent/expected revisions and native grants are still obtained/validated through existing action owners at submission. Implement HTTP/RPC/client parity deliberately, with per-operation refusal catalog/types and exact native reader authorization.

Actual-status filter is a separate choice. Earliest slice filters advisory copies and marks the selected page accordingly, then reads only its visible lanes to show actual state with provenance. A row whose actual state differs remains visibly stale/index-moved; do not claim an actual-status-complete page or exact total count. If product requires an ACTUAL current-status page, use a bounded lane-read closure over candidate rows: return partial/continuation and contributing heads when candidate budget ends; no false no-results. Full global actual-status completeness needs an adopted indexed-update/lane-head model or snapshot contract; it is not created by limited client verification.

Directory page enumeration uses its own single-domain indexed read budget; it does not include or promise actual verification of all25/50 lanes. Page verifies actual lane state in separate batches of at most20scope reads with at most4concurrent reads; remaining rows stay directory-advisory/verification-pending. No batch produces global actual-status completeness. Definition/source bytes use N1's separate reviewed bounds. Earliest query omits search; prefix search is offered only with an actual bounded index and explicit normalization, never unbounded substring scan. One selected publication operation page allows at most32operation records and64attempt records with continuation (96rows); its operation/attempt budget is separate from primary subject rows. It must not claim those96 plus extra primary records fit the100row component budget. Either separate the primary component or return incomplete before its combined allowance is exceeded. Size/row metadata must be checked BEFORE SQL JSON allocation; raw transport read is capped BEFORE joining/decoding. Bounds on field count/nesting/string/UTF8 and whole response serialization apply too.

Exhaustion is explicit budget-limited/incomplete with continuation when safe, or unreadable/query-limit when no resumable boundary exists. It never means absent, no matching publication, complete, or allowed. All proposed numeric constants need review against current native capacity/physical limits; they are query allowances, not global quotas or performance promises. No truncated known native answer or publication fact can earn a main confirmed state.

## Heads, provenance, completeness and movement

Each response names its domain owner's full ref and actual authenticated Read head; aggregate includes every contributing scope ref/head/pin and its role (directory-copy, lane-primary, membership standing, lane-held rules, destination publication, optional source). Server-authenticated projection is not a signed native event; it references native judged facts and disclosures. Actual signed reads verify caller/target/window, not an atomic cross-scope snapshot or a cryptographic signature over the entire projection. Do not call the vector “signed room head.” Current native read responses are trusted service reads.

Status is per component: complete-at-head, partial-with-next, unavailable with reason, forbidden/access-unavailable, not-found supported by complete owner lookup, and moved. Keep obtained content visible with its observed head when another optional family fails. Missing body/redaction differs from transport failure. Scope/incarnation mismatch is unusable; a foreign or stale lineage cannot substitute for selected facts. Membership/session failure blocks new action enablement while preserving original unknown command custody.

Single-domain cursors bind exact query parameters, normalized origin, reader context, schema/index revision, scope fullref/incarnation/head and last stable key. Authenticate or validate the bounded token server-side; no secrets in URL. Every next call reauthorizes current reader and compares domain head. If moved, return moved/restart-required, retaining the old visible page as stale. No silent skip/duplication or historical snapshot invented; old-head serving is unavailable unless an independently adopted retained-snapshot API exists. A vector page cannot continue atomically across many mutable lane scopes; its directory cursor governs candidate enumeration only, each visible lane's read is separately qualified. Restart is user-visible and deterministic; UI may deduplicate rows by fullref+number within that observation without claiming the union is complete. Index rebuild/incomplete generation is unavailable, not an empty registry. Deleted/retained history gap is incomplete/unavailable.

## Interim client changes, honestly bounded

Before server adoption, deduplicate concurrent identical authenticated reads within one selected context and run at most4independent visible reads in parallel; never deduplicate across origin/reader/key/incarnation/query/head. Cache only content/provenance at a stated head; cached standing is not permission. Render primary selected subject before optional inspection and cap concurrent optional families. Abort/cancel navigation reads and reject late repaint by selection generation; keep unrelated known/native command answers in their custody owner. This can improve latency and avoid duplicate work, but current summaries/full history still scale with room/history size. Client-only paging over all rows is not the server query contract or an asymptotic fix.

## Streams only invalidate

Current GET /v1/scopes/:scope/stream is authenticated application/x-ndjson, one {at:head} on open and after commits. Sessions are checked before sends; expired/disallowed/clock-behind closes without another byte. Cancel releases subscription; restart closes it. Backpressure allows one pending line and later heads may be coalesced. There is no replay cursor, Last-Event-ID recovery, acknowledged delivery sequence or notice-as-settlement API. Public client ScopeHandle has no stream helper; a small browser adapter remains owned work.

Observe only directory and selected lane/destination plus membership when needed; do not open a stream for every room lane. Proposed cap4connections, read frame4KiB and one debounced refresh in flight per component, owner-reviewed. A notice with newer head invalidates that component; same seq/different hash or different incarnation demands full authoritative reacquisition. Reconnect first fetches actual current components and then opens streams; close the race with one read-after-open comparison or a later notice/read, without claiming all intermediate events were delivered. Revoked/expired reader renews through actual membership only; forbidden clears action enablement, not historical acceptance. Existing tokens retain their actual native access-window semantics; no immediate revocation guarantee is introduced.

Missed/coalesced notice or retention gap triggers read/status-unavailable; never infer no state change. Stale notice is ignored only relative to exact same ref/head lineage, not used to restore authority. Cancelled navigation closes readers/streams and suppresses repaint, but does not cancel a submitted native mutation or erase its unknown envelope/answer. Session reconnect, query movement, subscription loss and command settlement are distinct states. Check original signed intent through existing settlement owner; current not-found is nonterminal. No generic outbox/device recovery is designed here.

## Acceptance and future one measurement

- visible kind/advisory status page has bounded server rows/bytes independent of total lane count; actual-status discrepancy stays qualified, not complete;

- selected old manifest/merge stays exact while newer lane/destination heads move; optional unavailable inspection does not hide primary subject;

- concurrent insertion/status update invalidates cursor deterministically; restart cannot lose/duplicate and then claim a complete page;

- wrongref/incarnation/reader, revoked/expired access and unsupported pin refuse before disclosure; index gap and byte/work exhaustion remain unavailable;

- same selected merge maps only exact native publication/receipt/operations; foreign operation or internally confirmed mint never earns Merged;

- stream reconnect/missed notice/coalescing/gap/cancelled navigation performs actual reads and preserves existing unknown command/known-answer custody;

- useful controls remove head binding/index completeness, substitute a foreign publication, or treat notice as command success; select only changed invariant witnesses once and one coordinated final gate after implementation.
