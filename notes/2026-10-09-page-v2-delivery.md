phone header identify the recorded room once. Issues and Changes have
search and state filters. Each detail has one current condition; only a
selected version's recorded publication earns Merged. Deeper authority,

## Eight design rules and evidence

| Rule | Witness |
|---|---|
| One default home per fact | View witnesses and desktop/phone captures; full records stay in inspection. |
| Controls explain actions | Native action forms, exact defaults and creation dialog; custom declared names remain own values. |
| Consistent outcome language | Selected-version view witness rejects an older merge and an internal effect as Merged. |
| Requirements at decisions | Native review refusal, invalid-path controls, Rules confirmation/cancel and pending read-only recovery. |
| Content over completion notices | Native comments, filtered work lists and saved-rule value reread; no duplicate success panel. |
| No false affordances | Role/declaration offers, single-choice control, state-blocked transitions and native founder/member creation visibility. |
| Preserve the subject | Authenticated source preview, exact version defaults, scoped drafts, stale-room guards and identical claim retry envelopes. Latest-page limitation is explicit. |
| Designed narrow layouts | 320/390px and dark captures, 16px editable text, 44px dialog targets and keyboard Escape/focus. |
